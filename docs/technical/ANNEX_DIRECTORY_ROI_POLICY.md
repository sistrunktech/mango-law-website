# Annex: Directory ROI Policy

## 1) Operating Principle

Default to free foundational listings until baseline data quality and attribution controls are complete.

## 2) Phase Model

Phase 1 (default):

- free listings only
- full optimization and NAP consistency

Phase 2 (controlled tests):

- one paid platform test at a time
- 45-day test window
- explicit monthly spend cap in task brief

## 3) Preconditions for Paid Tests

All required before test launch:

1. NAP consistency validated across GBP, Apple, Bing, and priority legal directories.
2. GBP profile completeness and recency checklist complete.
3. Attribution path and conversion tracking confirmed.
4. Pre-approved max signed-client CPA documented.

## 4) Conservative Go/No-Go Framework

Automatic no-go when:

- attribution is unclear
- signed-client CPA exceeds cap
- referral quality fails case-fit threshold

Continue only when:

- economics and referral quality both pass
- signal quality is stable across test window

## 5) Required Test Record

Each paid test must include:

- platform
- budget cap
- test window
- target query themes
- attribution method
- go/no-go thresholds
- final decision with rationale
