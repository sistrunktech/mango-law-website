# Annex: Roles and RACI

## 1) Roles

- `Owner`: business owner authority and final compliance signoff
- `Super Admin`: delegated final approver for governed tasks
- `SEO Ops`: SEO execution and reporting
- `Content Ops`: content drafting and quality controls
- `Agent`: automation actor (drafting, checks, implementation support)

## 2) RACI Matrix

| Workflow | Owner | Super Admin | SEO Ops | Content Ops | Agent |
| --- | --- | --- | --- | --- | --- |
| SEO sprint execution | A | R | R | C | R |
| Blog drafting | I | C | C | A/R | R |
| Blog finalization | A | A/R | C | R | C |
| Structured data update | A | R | R | C | R |
| Review solicitation policy | A | A/R | C | C | C |
| Review response draft approval | A | A/R | C | C | R |
| Directory paid test decision | A | R | A/R | C | C |

Legend:

- `R` responsible
- `A` accountable
- `C` consulted
- `I` informed

## 3) Approval Requirements

Mandatory Owner or Super Admin approval is required for:

- finalized content edits
- review solicitation language/policy
- incentive-related language decisions
- directory paid-spend go/no-go decisions
