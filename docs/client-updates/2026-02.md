# Mango Law — Monthly Update (Feb 2026)

Prepared for: Mango Law LLC
Reporting period: **December 2025 – January 2026** (work completed) + **February 2026** (plan)

## Executive summary

Over December and January we focused on strengthening Mango Law’s technical SEO foundation (crawlability, schema, indexing tooling) and improving the site’s overall trust signals and information architecture. The big theme was **making it easier for search engines to discover, crawl, and correctly interpret the site**, while also improving the user journey (clear navigation, credible sources, and faster page loads).

For February, we’ll shift to:
- **Local citations** (NAP consistency + priority directory submissions)
- **Monitoring and improving performance signals** (organic traffic, rankings, indexing trends)
- **Backlink outreach strategy** (repeatable process + target list)

## December 2025 — Work completed

### Technical SEO + crawlability
- Implemented a content governance system (to protect finalized content and ensure changes are logged and reversible).
- Began/advanced the Next.js migration foundation for improved SSR/SSG crawlability.

### Performance baseline
- Captured a PageSpeed baseline and documented a prioritized improvement path (image delivery, render-blocking resources, third-party impact).

## January 2026 — Work completed

### Crawlability + indexing
- Migrated the site to **Next.js App Router SSR/SSG** and expanded **server-rendered metadata + schema** (FAQ/Breadcrumb/Article) to improve crawl quality and rich result eligibility.
- Shipped discovery-surface improvements (`llms.txt`) and aligned crawler controls with Next.js route-based `sitemap.xml` and `robots.txt`.
- Added best-effort **IndexNow ping automation** to accelerate sitemap discovery (non-blocking).

### Search Console audit + indexing diagnostics
- Reviewed Google Search Console indexing state and documented the findings and action plan.
- Identified that the primary bottleneck appears to be **crawl/index prioritization** (“Discovered – currently not indexed”), with a secondary issue of intermittent **5xx** errors that should be treated as P0 when present.

### Internal linking improvements
- Added internal links from the footer to key pages/posts with low internal link coverage to improve crawl paths and distribute internal authority.

## Current work in progress (pending go-live)

### Outgoing link policy optimization (SEO hygiene)
Status: **Implemented locally; pending commit/merge to production**.

What this change does:
- **Default stance:** external links are `nofollow` to avoid leaking link equity and to keep outbound link profile clean.
- **Selective dofollow:** blog “Sources” panels allow **up to 2 dofollow** citations to **high-authority `.gov` / `.edu`** domains per post (the rest remain `nofollow`).
- **Security:** all external links continue to use `rel="noopener noreferrer"` when `target="_blank"`.
- **Consistency:** footer developer credit link is `nofollow`.

Expected outcome:
- Cleaner outbound link graph (reduces unintended endorsement signals)
- Still allows a limited “trust budget” for authoritative citations in editorial contexts

## February 2026 — Plan

### 1) Local citations (priority)
Goal: build local trust signals and consistency across major business directories.

Scope:
- Audit NAP consistency (Name / Address / Phone) and standardize canonical formatting.
- Submit/claim priority citations (core aggregators + high-value legal/local directories).
- Track progress in a shared sheet/list (submitted / pending / live URLs).

Deliverables:
- NAP canonical reference (single source of truth)
- Priority citation list + status
- Follow-up cadence (weekly) until listings stabilize

### 2) Monitor and improve performance signals (traffic + rankings)
Goal: establish a reliable weekly “SEO health check” loop.

Monitoring:
- Google Search Console: indexing trends, top queries/pages, coverage exclusions, sitemap processing.
- Rankings: track priority keywords and their target pages; identify winners/losers.
- Organic traffic: top landing pages and assisted conversions.

Actions:
- Identify pages with impressions but low CTR → improve title/description alignment.
- Identify pages with rankings near page-1 threshold → strengthen internal links + add supporting content.

### 3) Site performance improvements (speed + UX)
Goal: improve Core Web Vitals and perceived performance, especially on mobile.

Targeted work:
- Reduce oversized hero imagery by adding responsive delivery and modern formats (WebP/AVIF where appropriate).
- Minimize render-blocking resources where feasible.

### 4) Backlink outreach strategy (repeatable process)
Goal: build a durable authority flywheel; avoid one-off outreach.

Strategy outline:
- Define “linkable assets” worth referencing (examples: DUI checkpoint map resource hub, high-quality statutory explainers, updated/localized intent pages).
- Create a target list:
  - Local organizations (community groups, chambers)
  - Local sponsorship/opportunity pages
  - Legal associations/directories
  - `.gov/.edu` resource pages where relevant and appropriate
- Outreach workflow:
  - Target identification → pitch angle → outreach email → follow-up cadence → tracking

Deliverables:
- Target list (first pass)
- Outreach templates (2–3 variants)
- KPI tracking: new referring domains per month + DR trend
